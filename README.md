# Background Image Editor

배경 이미지 위에 이미지와 텍스트를 자유롭게 배치하고 PNG로 저장할 수 있는 브라우저 기반 편집기입니다.

## 실행 방법

별도의 설치 없이 `index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.

```
index.html  ← 브라우저로 열기
```

## 기능

### 배경 이미지
- 파일 선택 버튼 또는 캔버스 영역에 드래그 앤 드롭으로 업로드
- 업로드 시 이미지 원본 해상도로 캔버스 크기 자동 설정
- 캔버스 크기를 직접 입력해 변경 가능 (최대 4000×4000)

### 이미지 에셋
- `+ 이미지 추가` 버튼으로 이미지 파일 업로드
- 추가한 이미지는 **최근 이미지** 목록에 자동 저장 (최대 10개)
- 썸네일 클릭으로 재사용 가능, 개별 삭제 가능
- 조절 가능한 속성: 위치 / 크기 / 회전 / 둥글기 / 투명도
- 크기 조절 시 `Shift` 키를 누르면 비율 유지

### 텍스트
- 왼쪽 패널 텍스트 입력란에 작성 후 추가 (`Ctrl+Enter` 단축키 지원)
- 추가한 텍스트는 **최근 텍스트** 목록에 자동 저장 (최대 10개)
- 텍스트 선택 해제 시 수정된 내용이 최근 목록에 자동 반영
- 조절 가능한 속성: 내용 / 위치 / 크기 / 색상 / 폰트 / 굵기 / 회전 / 투명도

### 인터랙션
- 요소 클릭으로 선택
- 드래그로 이동
- 모서리 핸들 드래그로 크기 조절
- 상단 빨간 원 핸들 드래그로 회전 (`Shift`로 15° 단위 스냅)
- `Delete` / `Backspace` 키로 선택 요소 삭제

### 레이어 관리
- 오른쪽 패널 **레이어** 탭에서 전체 요소 목록 확인
- 레이어 순서 위아래 이동 가능
- 레이어 클릭으로 요소 선택

### 프리셋
- 현재 요소 배치 상태를 이름을 붙여 저장
- 언제든 불러와서 재사용 가능 (배경 이미지는 유지됨)
- 저장된 프리셋은 개별 삭제 가능

### 줌
- `+` / `−` 버튼 또는 `Ctrl + 스크롤`로 줌 조절
- ⊡ 버튼으로 캔버스를 화면에 맞춤

### 다운로드
- `다운로드` 버튼 클릭 시 현재 상태를 PNG로 저장
- 파일명 형식: `bg-editor-YYYY-MM-DD-HH-MM-SS.png`

## 제한 사항

| 항목 | 제한 |
|------|------|
| 에셋 이미지 크기 | **5MB 이하** 권장 |
| 최근 이미지 저장 수 | 최대 10개 |
| 최근 텍스트 저장 수 | 최대 10개 |
| 캔버스 최대 크기 | 4000 × 4000px |

> **이미지 크기 제한 안내**  
> 최근 이미지 목록과 프리셋은 브라우저 `localStorage`에 저장됩니다.  
> localStorage의 저장 용량은 브라우저마다 다르지만 일반적으로 **5~10MB**로 제한되어 있습니다.  
> 에셋으로 사용하는 이미지가 너무 크면 저장에 실패할 수 있으므로, **단일 이미지는 5MB 이하**를 권장합니다.  
> 저장 실패 시 화면 하단에 안내 메시지가 표시됩니다.

## 파일 구조

```
background-image-editor/
├── index.html   # UI 마크업
├── style.css    # 스타일 (다크 테마)
└── app.js       # 전체 애플리케이션 로직
```

## 로컬스토리지 키

| 키 | 내용 |
|----|------|
| `bge_recentImages` | 최근 사용한 이미지 목록 (압축 저장) |
| `bge_recentTexts` | 최근 사용한 텍스트 목록 |
| `bge_presets` | 저장된 프리셋 목록 |

## 지원 브라우저

Canvas API와 localStorage를 지원하는 최신 브라우저 (Chrome, Edge, Firefox, Safari)
